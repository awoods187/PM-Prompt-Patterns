# Customer Research

## Available Prompts

- **[Product Feedback Call Notes](./call-notes/)** - 🟡 Intermediate (Claude Code skill)
  - Turns a customer or prospect call transcript into internal feedback notes as a Google Doc
  - Leads with the deal status, links every feature ask to its Linear project, flags asks that already exist
  - **Best for**: Lost-deal, churn, win-back, and advisory board calls

- **[Closed-Lost Thank-You Email](./closed-lost-thank-you/)** - 🟢 Beginner (Claude Code skill)
  - Turns lost-deal notes into a short thank-you email from the head of product
  - Uses the buyer's own words, confirms roadmap status instead of guessing, never pitches
  - **Best for**: Closing the loop with buyers who gave product feedback

- **[Closed-Lost Feedback Agent](./closed-lost-feedback-agent/)** - 🔴 Advanced (scheduled automation)
  - Weekly agent that qualifies closed-lost HubSpot deals and drafts product-led feedback emails in Gmail
  - Pulls loss reasons from call recordings, Slack, and CRM; never sends; dedupes via a sent log
  - **Best for**: Running a product-led closed-lost outreach playbook without manual deal review
